Cisco Packet Tracer Labs

This section documents practical networking exercises completed using Cisco Packet Tracer.

Purpose

The goal of these labs is to practice Cisco device configuration and understand how networking concepts work in simulated environments.

Lab Documentation Format

Each lab should include the following information:

- Objective: What the lab is intended to demonstrate.
- Topology: The devices and connections used.
- Configuration: The commands entered on each device.
- Verification: The checks used to confirm the configuration.
- Result: What happened during the lab.
- Lessons Learned: What I learned from completing the exercise.

Important Note

Only labs that I have actually completed will be marked as completed. The topics listed above are planned documentation items, not claims that every lab has already been performed.
