## Lab Documentation Format

Each lab should include the following information:

- **Objective:** what the lab is intended to demonstrate.
- **Topology:** the devices and connections used.
- **Configuration:** the commands entered on each device.
- **Verification:** the checks used to confirm the configuration.
- **Result:** what happened during the lab.
- **Lessons Learned:** what I learned from completing the exercise.
