## Documentation Principles

- Document useful findings in my own words.
- Include source links when information comes from external material.
- Distinguish between information I have read, concepts I understand, and tasks I have personally tested.
- Include screenshots, configurations, and other evidence when useful.
- Never publish passwords, access tokens, private keys, or other sensitive information.
- Avoid duplicating content already documented in the main [Linux](../Linux/), [Networking](../Networking/), or [Cisco](../Cisco/) sections.
