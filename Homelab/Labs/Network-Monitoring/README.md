# Network Monitoring

- **Category:** Networking, Network Security
- **Status:** In Progress

## Overview

This lab focuses on observing network traffic, understanding TCP connection behavior, and investigating methods for detecting network scans.

## Objectives

- Observe network traffic using Wireshark.
- Understand TCP connection establishment and responses.
- Investigate how port scans can be identified.
- Explore firewall rules and their effects on network traffic.
- Research Intrusion Detection Systems (IDS) and Intrusion Prevention Systems (IPS).

## Tools

- Nmap
- Wireshark
- Windows Firewall
- Linux command-line tools

## Experiments

### Network Traffic Analysis

Captured and examined network traffic generated during Nmap scans in a controlled lab environment.

### TCP Connection Behavior

Observed TCP packets and investigated connection patterns, including:

- SYN
- SYN-ACK
- ACK
- RST-ACK

### Firewall Behavior

Experimented with Windows Firewall rules and observed their effects on scan results, network responses, and connectivity.

### Scan Detection Research

Investigated methods for identifying port scans and explored the role of IDS/IPS solutions, including Snort. See the related lab: [Snort 3 Network Scan Detection](../Network-Monitoring/Snort-3/).

## Status

In progress. Experiments and observations are documented as they are performed.
