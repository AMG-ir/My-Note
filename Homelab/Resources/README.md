Resource Guidelines

- Prefer official documentation and reputable sources.
- Add a short description explaining why each resource is useful.
- Verify links before adding them.
- Use direct links to the relevant documentation or resource whenever possible.
- Keep entries organized by category.
- Avoid adding duplicate or low-value links.
- Do not imply that a course or resource has been completed merely because it is listed here.
- Add personal notes about a resource when they provide useful context.
