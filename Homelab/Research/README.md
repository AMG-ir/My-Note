Use a short, descriptive directory name for each topic. For small findings that do not need a separate directory, add them directly to this section's README only when appropriate.

## Research Documentation Template

Each research topic should include the following sections when relevant.

1. **Research Question**

   Clearly state the question or problem being investigated.

2. **Purpose**

   Explain why the topic is worth investigating.

3. **Background**

   Provide the necessary context to understand the subject.

4. **Sources**

   List the documentation, articles, websites, or other sources used. Prefer official documentation and reliable technical references when available.

5. **Findings**

   Summarize the relevant information gathered from the sources in your own words.

6. **Analysis**

   Explain what the findings mean and how they relate to the research question. For comparisons, describe the important differences, advantages, limitations, and use cases.

7. **Practical Verification**

   Document any commands, configurations, or experiments used to verify the findings. Clearly distinguish information learned from reading from information verified through practical testing. If no practical testing was performed, state that explicitly.

8. **Conclusion**

   Summarize the answer to the original research question. Mention any remaining uncertainties or topics that require further investigation.

9. **References**

   Include links to the original sources and any related notes, labs, or projects.

## Research Guidelines

- Write summaries in your own words.
- Include source links for important claims.
- Prefer reliable and up-to-date technical documentation.
- Verify important claims when practical.
- Distinguish confirmed facts from assumptions and personal analysis.
- Do not present untested ideas as verified results.
- Avoid copying substantial portions of copyrighted material.
- Link to existing notes instead of duplicating them.
